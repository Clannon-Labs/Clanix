# Clanix

First commit of Clanix - [Cybro](https://github.com/thecybro)

## Supported type of commands (basic for now): 
> Note that the initial cargo run will be replaced by clanix when running from the binary

> (basic)
- `cargo run run cargo new project -p output2.txt`
> (chained)
- `cargo run -- -v -s output3.txt run cargo new project2 -p output4.txt`
