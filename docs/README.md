# Clanix Docs

This directory contains 2 sub directories: **clanix-cli** and **clanix**.

- **clanix-cli** is the documentation of the tool or binary we use.

- **clanix** is the documentation of the underlying library *clanix* uses; which can also be used by anyone in their projects.
You can get it on crates.io and see the detailed documentation on [clanix](https://docs.rs/clanix).

> Note that the core library is called `clanix` and you download it by doing `cargo install clanix` (only after it's published to crates.io)
> However if you want the cli/binary of clanix, you download it by doing `cargo install clanix-cli` or by
> directly running the installation script that is/will be provided
