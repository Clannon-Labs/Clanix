# Clanix Docs

This directory contains 2 sub directories: **clanix** and **libclanix**.

- **clanix** is the documentation of the tool or binary we use.

- **libclanix** is the documentation of the underlying library *clanix* uses; which can also be used by anyone in their projects.
You can get it on crates.io and see the detailed documentation on [libclanix](https://docs.rs/libclanix).
